# EpistemicDB

A research project exploring safe, economical reuse of agent-acquired knowledge. The long-term vision is an agent-native data system; the evidence may instead support a library, gateway or database extension. No claim of novelty or proven performance is made.

## First experiment (E001)
Can execution-derived observation receipts and materiality-aware validation reduce total investigation cost at matched correctness, freshness and authorization compared with strong TTL, prompt-cached recomputation and exact query replay baselines? Map the regimes where each approach wins. Exact replay is a serious candidate, not a straw man.
